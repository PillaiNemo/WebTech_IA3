# static/

Plain HTML pages (Modules 1 to 3) that need no build step. Open them by double-clicking (an internet connection is needed for Google Fonts, Bootstrap and jQuery from their CDNs). While the servers run they are also at http://localhost:5173/static/.

| File | What it shows |
| --- | --- |
| `about.html` | Semantic layout, sticky table of contents, a table with a caption, `<video>` with captions, jQuery `slideToggle` and `fadeIn` |
| `how-it-works.html` | Ordered steps with jQuery traversal, `<audio>` with a mute switch, a jQuery `.animate()` duplicate-merge demo, the FAQ accordion, a status table |
| `contact.html` | A form with vanilla JS validation (`js/contact.js`), jQuery field access and manipulators, an OpenStreetMap `<iframe>`, a helpline table, a honeypot |
| `style-guide.html` | The living design system |
| `css/civicfix.css` | The shared design system (also used by the React app) |
| `css/pages.css` | Extra styles for these pages (gradients, box model, position properties) |
| `js/civicfix-ui.js`, `js/civicfix-jquery.js` | Shared vanilla JS and jQuery helpers (also used by the React app) |
| `js/site.js`, `js/contact.js` | Page scripts |
| `images/`, `media/` | Illustrations; the intro video, its captions and the status chime (made for this project) |
