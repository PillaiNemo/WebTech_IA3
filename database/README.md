# database/

Module 5 (MongoDB) material:

- `queries.md`: mongosh commands for creating the database and collection, insert, find, update, delete, query operators (`$gt`, `$in`, `$regex`, `$and`), projections, aggregation and indexes
- `seed-issues.json`: the sample data. `npm run seed` (in `server/`) expands it into 52 issues across 10 states, with 6 duplicate clusters (one already merged), 2 hidden spam reports, escalated issues, and resolved/reopened examples
